## 0. この文書について

引き継ぎ書で合意した方向性を、遊べる仕様へ具体化した設計書。試作（`index.html` ほか）はこの設計書に沿って作る。仕様を変えたときは、この文書を先に（または同時に）更新する。引き継ぎ書は受け取った時点の記録として残し、書き換えない。

### 0.1 記載区分

| 表記 | 意味 |
|---|---|
| **決定** | ユーザーが選択・指示・承認した方針。変えるときはユーザーに確認する |
| **仮** | 試作のために置いた仕様・数値。遊んだ結果で変えてよい |
| 未決定 | まだ決めていない。試作では未実装か、最小限の代用 |
| 将来構想 | 初期版に入れず、拡張候補として残すもの |

方向性が「決定」でも、具体的な数値や一覧は「仮」の場合がある。各節の見出しに区分を書く。「決定：D20／内容は仮」は、入れることはユーザーが決めたが、中身（種類・式・数値）はまだユーザーの承認を受けていないことを表す。

D17（U01〜U10の承認）で「決定」になった節の数値（成長の係数、確率、人数など）は、遊びながら微調整してよい。ただし、調整した内容は必ずこの設計書に記録する。仕組みそのものを変えるとき（例：ターンの単位、素質の段階数）はユーザーに確認する。

## 1. ゲーム概要

### 1.1 コンセプト（決定）

人材の才能を見抜き、育て方と組み合わせで未来を変える、歴史蓄積型の音楽事務所育成シミュレーション。

プレイヤーは音楽事務所を運営し、オーディションやスカウトで人材を発掘する。能力・適性・相性を見ながらトレーニングと活動形態（ソロ、バンド、アイドル、ラッパーなど）を決める。育った能力は自動で作られる楽曲やライブに反映され、チャート・ダウンロード数・音楽賞での活躍が事務所の歴史として積み重なる。所属アーティストは年を取り、やがて引退や独立で事務所を去っていく。

### 1.2 体験の柱（決定）

1. 発見する楽しさ：候補者の能力・個性から、育てたい人物を見つける
2. 育てる手応え：才能だけで結果が決まらず、方針や扱い方で成長が変わる
3. 適性を生かす自由：活動形態やメンバー構成を変え、その人に合う道を探せる
4. 活躍を見届ける喜び：能力が楽曲や実績に結びつく
5. 歴史が残る満足感：作品と人物の歩みが蓄積する
6. 短時間で関われる手軽さ：毎回大量の細かい操作を要求しない

### 1.3 提供形態（決定：D31）

当面はWebブラウザのみで遊ぶ。ファイルをダブルクリックすれば動く静的ファイル構成で、サーバー・オンライン機能はなし。アプリ化するかどうかは未定。

## 3. ゲームの流れ

### 3.1 開始（決定：D17）

1. 事務所名を入力して設立する。
2. 所属0人で始まり、発掘タブで最初の春のオーディション（候補6人）が開かれている。
3. 人材を迎え、活動形態を編成し、トレーニングを決めて時間を進める。

### 3.2 ターン（決定：D17・D21・D30）

- 1ターン＝1季節（春・夏・秋・冬）。年4ターンで、1年目から年数が続く。
- ターン中にプレイヤーができること：トレーニングの変更、編成・転向・解散、発掘（迎え入れ・スカウト）、推しの指名、契約終了。回数の制限はスカウト（1季1回）だけ。
- 「次の季節へ」を押すと、次の順で処理する（仮）。
  1. 相性の判明（同じ組のメンバー同士、同じトレーニングの人同士）
  2. 全員の育成（トレーニング成長 → 自然な増減 → 調子の増減 → 才能開花の判定）
  3. 新曲を出さない季節の組がライブを行う。夏は夏フェスも行う
  4. 発表時期を迎えた組が新曲を発表
  5. ライバルの新曲（5曲）を追加
  6. チャートを更新し、ダウンロード数とファン数を加算
  7. イベントの発生（強制イベントはここで効果が出る。選択肢つきは保留）
  8. 冬なら年間チャートと音楽賞を確定
  9. 季節を進める。春なら全員が1歳年を取り、ライバルが入れ替わり、オーディションの候補を生成。候補者の入れ替えとスカウト回数の回復
  10. 評価コメントを書き直す
  11. 季節の結果ポップアップを表示する（5.3）。選択肢つきのイベントがあれば、先にそれを選ぶ
- 選択肢つきのイベントが残っている間は、次の季節へ進めない。
- プレイ時間・ボリューム感は今のままとする（D30）。

### 3.3 終了（決定：無期限）

ゲームオーバーや期間による終了はない。ブラウザに自動保存され、いつでも中断・再開できる。

## 4. システム仕様

### 4.1 人材

#### 能力（決定：D12・D17）

| キー | 名前 | 範囲 |
|---|---|---|
| sing | 歌唱 | 1〜100 |
| play | 演奏 | 1〜100 |
| comp | 作曲 | 1〜100 |
| dance | ダンス | 1〜100 |
| expr | 表現 | 1〜100 |
| char | カリスマ | 1〜100 |

内部では小数で持ち、表示は切り捨てにする。

#### 総合値と向いている形態（決定：D22）

- 総合 = 上位3能力の平均 × 0.7 ＋ 全能力の平均 × 0.3（四捨五入）。得意分野がはっきりした人も評価されるようにしている。
- 向いている形態：本人の能力だけで各活動形態の楽曲力（重みつき合計）を計算し、上位2つを表示する。
- 所属カード、候補者カード、編成フォーム、トレーニング部屋、季節の結果に表示する。

#### 素質（決定：D17。S〜Dの表示はD18）

- 能力ごとに隠れた素質値（25〜99）を持つ。成長の速さと、成長が鈍り始める目安になる。
- 表示ランク：S（90以上）／A（80以上）／B（65以上）／C（50以上）／D。
- 最初は「?」表示。その能力を育てた度合い（下記）が2以上になると判明し、能力バー上に縦線で位置が表示される。
  - 能力の重みが0.9以上のトレーニングを1季受けると+1、0.4以上で+0.4、それ未満で+0.2。
- 素質は固定ではない。才能開花（4.3）で伸びることがある。

#### 年齢（決定：D27）

- 発掘時の年齢：オーディション15〜26歳。スカウトは場所ごとに異なる（4.2）。
- 毎年春に全員が1歳年を取る。
- 年齢による成長の補正（トレーニング）：20歳未満×1.15、20〜25歳×1.0、26〜30歳×0.85、31〜35歳×0.7、36歳以上×0.5。
- 自然な伸び：20歳未満は確率×1.2、31歳以上は×0.6。
- 衰え：31歳以上は、鈍る確率が1歳ごとに+1.5%。33歳以上は、トレーニングしている能力も半分の確率で鈍る。
- 初期能力は年齢が高いほど少し高い（(年齢−18)×0.5）。
- 引退・独立は4.10のイベントで起きる。

#### 個性（決定：D17・D20）

1人につき1つ。35%の確率で2つ目を持つ。ただし、早熟と晩成、タフと怪我しやすい、リーダー気質と一匹狼、タフと繊細は同時に持たない。

| 個性 | 効果 |
|---|---|
| 天才肌 | トレーニング成長×0.9〜1.7（ばらつき大）。自然に伸びる確率×1.6 |
| 努力家 | バランス以外のトレーニングで成長×1.2。素質を超えてからの成長が鈍りにくい（×0.45。通常は×0.2） |
| 本番に強い | 楽曲ボーナス+5%（1組あたり最大+10%）。ライブ力×1.1 |
| スランプ気味 | 休養以外の季節に15%でトレーニング成長なし。使わない能力が鈍る確率12%（通常7%） |
| ムードメーカー | 2人以上の組で楽曲ボーナス+4%。同じ組の仲間の調子の消耗−3。相性+12 |
| 晩成 | 所属から8季未満はトレーニング成長×0.8、8季以降は×1.35。8季以降は自然に伸びる確率×1.5 |
| 早熟 | 所属から8季未満はトレーニング成長×1.3、8季以降は×0.8 |
| タフ | 調子の消耗−4 |
| 繊細 | 表現のトレーニング成長×1.3。楽曲ボーナス+3%。調子の消耗+3 |
| 自由人 | トレーニング成長×0.85。自然に伸びる確率×1.6 |
| 完璧主義 | 楽曲ボーナス+5%。調子の消耗+2 |
| 一匹狼 | 1人の組で楽曲ボーナス+6%、グループでは1人につき−4%。相性−15 |
| リーダー気質 | 2人以上の組で楽曲ボーナス+4%。相性+8 |
| 器用 | バランストレーニングの成長×1.4 |
| 話題性 | 所属する組のファンの増え方×1.25。SNSでバズるイベントが起きやすい |
| 負けず嫌い | トレーニング成長×1.1。同じトレーニングの仲間との相性が0以上なら切磋琢磨できる（通常は+20以上が必要） |
| 目立ちたがり | カリスマのトレーニング成長×1.3。目立ちたがり同士は相性−20 |
| 天然 | 相性+8 |
| 怪我しやすい | 怪我のイベントが4倍起きやすい |
| 天性の声 | 歌唱のトレーニング成長×1.25、歌唱が自然に伸びる確率×1.25 |

#### 調子（決定：D17）

- 0〜100の値で、初期値は80。範囲は10〜100に制限する。
- トレーニング（4.3）、ライブ（−4）、イベント、組の相性の悪さ（4.4）で変わる。
- 成長量と楽曲の出来に影響する（4.3、4.6）。
- 35未満で警告表示を出し、休養をすすめる。

#### 推し（決定：D16・D17）

- 最大3人まで指名できる。
- 効果：トレーニング成長×1.15、自然に伸びる確率×1.3、調子の消耗−2。
- 所属一覧の先頭に並ぶ。指名と能力の到達が年表に★付きで記録される。

### 4.2 発掘（決定：D04・D17・D24）

| 手段 | 頻度 | 候補数 | 年齢 | 特徴 |
|---|---|---|---|---|
| オーディション | 毎年春 | 5人（初回のみ6人） | 15〜26歳 | 偏りなし |
| スカウト | 毎季1回 | 2人 | 場所による | 場所によって得意分野が偏る |
| 街角（イベント） | 不定期 | 1人 | ランダムな場所の範囲 | 「気になる才能」イベントで声をかけたとき。見込み★+1 |

| スカウト場所 | 素質の偏り（加算値） | 年齢 |
|---|---|---|
| ライブハウス | 演奏+14、作曲+10 | 18〜30歳 |
| ダンススクール | ダンス+14、カリスマ+8 | 14〜22歳 |
| 路上ライブ | 歌唱+14、表現+10 | 16〜27歳 |
| SNS | 作曲+12、表現+8 | 14〜24歳 |

- 候補者はその季節の間だけ迎え入れられる。費用はかからない。
- 発掘時に見える情報：年齢、総合、向いている形態、現在の能力、個性、見込み★1〜5（推定値でずれがある）、一番素質の高い能力のヒント、スカウト担当のメモ（4.12）。素質値そのものは見えない。

#### 候補者の生成式（決定：D17）

- 才能基準値 = 40〜78
- 素質 = 才能基準値 + (−22〜+18) + 場所の偏り（25〜99に制限）
- 初期能力 = (10〜28) + 偏り×0.8 + (素質−50)×0.22 + (年齢−18)×0.5（3〜60に制限）
- 見込み★ = 素質平均÷18 ± 0.7 を四捨五入（1〜5）

#### 人名（決定：D24）

- 姓 約150種 × 名 約110種からランダムに作る。名には漢字・ひらがな・カタカナの名前を混ぜる。
- 所属中・退所済み・候補者の名前と重ならないように、最大30回作り直す。

### 4.3 育成

#### トレーニング（決定：D12・D17）

1人ずつトレーニングを選ぶ。季節ごとに変更できる。トレーニングタブでは部屋として表示する（5.1）。

| トレーニング | 伸びる能力（重み） | 調子 |
|---|---|---|
| バランス | 全能力（0.4） | −8 |
| ボイストレーニング | 歌唱◎（1.0） 表現△（0.25） | −10 |
| 楽器練習 | 演奏◎（1.0） ダンス△（0.25、リズム感） | −10 |
| 作曲合宿 | 作曲◎（1.0） 表現○（0.45、作詞） | −10 |
| ダンスレッスン | ダンス◎（1.0） カリスマ○（0.4） 表現△（0.2） | −12 |
| ステージ経験 | カリスマ◎（0.75） 表現◎（0.75） 歌唱△（0.2） 演奏△（0.2）。未編成なら効果半減 | −14 |
| 休養 | なし | +35 |

#### トレーニング成長の式（決定：D17）

成長量 = 5 × 重み × (0.6 + 素質/150) × (0.5 + 調子/200) × 年齢補正 × 乱数(0.7〜1.3)

これに個性・推し・切磋琢磨（4.4、×1.15）の補正を掛ける。能力が素質以上のときは×0.2（努力家は×0.45）になり、結果に「※素質の壁」と表示する。能力の上限は100。

#### 自然な増減（決定：D13・D17）

トレーニングとは別に、能力ごとに毎季判定する。

- **自然に伸びる**：能力が素質未満のとき、確率 = 0.04 + (素質−能力)/300（個性・推し・年齢で補正）で、+0.8〜2.2。
- **鈍る**：その季節にトレーニングしていない能力が35を超えているとき、確率7%（スランプ気味は12%、31歳以上は加算）で、−0.8〜2.2。伸びる判定に当たった能力は鈍らない。
- 結果に「自然：作曲+1 演奏−1」の形で表示する。

#### 才能開花・スランプ（決定：D17）

| 名前 | 条件 | 効果 |
|---|---|---|
| 才能開花 | バランス・休養以外のトレーニング中、スランプでない、調子50以上で、6% | 主に伸ばしている能力の素質+6〜10（上限99）。その素質が判明する。年表に記録 |
| スランプ | 個性「スランプ気味」（4.1） | その季のトレーニング成長なし |

この2つは育成の処理の中で判定する。そのほかのイベントは4.10。

### 4.4 相性（決定：D28）

#### 相性の値

- 2人の組み合わせごとに、−60〜+60の隠れた値を持つ。最初に必要になったときに決まる。
- 初期値 = 乱数(−30〜+30) ＋ 2人の個性による補正（ムードメーカー+12、リーダー気質+8、天然+8、一匹狼−15。目立ちたがり同士は−20）。
- 表示：◎抜群（+25以上）／○良い（+8以上）／△ふつう（−7以上）／▲悪い（−24以上）／×最悪。

#### 判明のしかた

- 同じ組のメンバー同士は、季節を1回越えると判明する（「組んでみたら相性が悪かった」）。
- 同じトレーニングの部屋にいる人同士も、季節を1回越えると判明する。
- 判明した相性は、所属カード（良い相手・悪い相手を最大3人ずつ）、編成フォーム（選択中のメンバーとの相性）、組のカード（メンバー全体の平均）に表示する。

#### 相性の効果

| 場面 | 効果 |
|---|---|
| 組の楽曲 | メンバー全ペアの平均 ÷ 250 を楽曲ボーナスに加える（−15%〜+12%）。判明前は「相性?」と表示 |
| 組の調子 | 平均が−15以下なら、メンバーの調子の消耗+4 |
| 切磋琢磨 | 相性+20以上（負けず嫌いは0以上）の人が同じトレーニングをしていると、トレーニング成長×1.15。トレーニング部屋に「切磋琢磨：A×B」と表示 |
| イベント | 平均+20以上で「化学反応」、−10以下で「メンバーの不和」、−25以下で「解散の危機」が起きる（4.10） |
| 変化 | 誕生日サプライズ（+5）、夏合宿（+6）、話し合い（+20）、解散の危機で活動を続ける（−5） |

#### 編成ルール（決定：D06・D17）

- 1人が所属できる組は1組まで（兼任なし）。未編成の人は「研修生」として育成だけを受ける。
- 結成、メンバーの追加・離脱、形態の転向、改名は、季節中いつでもできる。
- 別の組のメンバーを選ぶと、その人は移籍する。人数が最小人数を下回った組は「活動休止」になる。
- **変更の代償**：メンバーや形態を変えると、結束ボーナスがリセットされる。また、変えた季節は新曲を発表しない（準備期間）。改名だけなら代償はない。
- 解散・活動休止した組も記録として残り、歴史タブで見られる。

#### 命名（決定：D15・D17・D19）

- 編成画面に名前の候補を6つ表示する。「別の候補」で何度でも作り直せる。候補をクリックで選ぶか、自由に入力する。空欄のまま決定すると自動で命名する。
- グループ名の生成パターン：カタカナ複合（ネオンパレード等）、The＋英語（The Lonely Wolves等）、英大文字の単語（NOVA X等）、日本語複合（群青アパート等）、ひらがな（ひだまり日和等）、英語2語。意味のない英字の並び（「ZWZ」等）は作らない。
- 1人の形態の名前：本名、下の名前、芸名風（KAI、sora等）。ラッパーは「MC」「Lil」「Young」が付くことがあり、DJは「DJ ○○」「○○ Beats」等になる。

### 4.6 楽曲（決定：D07・D17）

#### 発表の周期

- 結成（または編成変更）した次の季節に1曲目を発表し、その後は2季ごとに発表する。新曲を出さない季節はライブを行う（4.7）。
- 編成画面に「今季の終わりに新曲を発表」「N季後に新曲」と表示する。

#### 楽曲力と出来

- 組としての能力値：作曲とカリスマはメンバーの最高値を使い、それ以外はメンバーの平均値を使う。
- 楽曲力 = Σ(形態の重み × 組としての能力値) × (1 + ボーナス) × (0.85 + 平均調子/100 × 0.15)。1〜100に制限する。
- ボーナス：個性（本番に強い・完璧主義・繊細・一匹狼・ムードメーカー・リーダー気質、4.1）、結束（結成からの季数×2%、最大+10%、2人以上の組）、相性（4.4）。
- 出来 = 楽曲力 × 乱数(0.9〜1.1) を整数にしたもの。
- 作曲者：発表時点で作曲が最も高いメンバー。最優秀作曲賞（4.9）の対象になる。
- 編成画面に楽曲力とその内訳（能力値×重み、補正、平均調子）を表示する。

#### 曲名（決定：D15・D17）

日本語の修飾語＋名詞、漢字の単語、日本語のフレーズ、英語2語、英語のフレーズ、「X of the Y」、漢字の単語＋の＋名詞、カタカナ語、日本語（英語）の混合、の9パターン。実在する有名曲と同じ題名にならないように素材を選ぶ。

### 4.7 ライブ・夏フェス（決定：D26）

#### ライブ

- 結成から1季以上たった組は、新曲を出さない季節に自動でライブを行う。
- ライブ力 = カリスマ×0.35 ＋ 表現×0.3 ＋ max(歌唱, 演奏, ダンス)×0.35（組としての能力値）。本番に強いメンバーがいれば×1.1。
- 会場はファン数で決まる。

| 会場 | 収容 | 必要ファン数 |
|---|---|---|
| ライブハウス | 300人 | 0 |
| ホール | 2,000人 | 3,000 |
| アリーナ | 15,000人 | 25,000 |
| ドーム | 50,000人 | 100,000 |

- 動員 = min(収容, 60 ＋ ファン数 × 0.25 × (0.5 ＋ ライブ力/100))
- ファンの増加 = 動員 × (0.1 ＋ ライブ力/400) × 話題性補正
- メンバーの調子−4。
- 初めてホール・アリーナ・ドームで公演したときは年表に記録する。

#### 夏フェス

- 夏の処理で、結成から1季以上たち、ファン2,000人以上の組が出演する。
- 出演枠：サブステージ（2,000人以上）／メインステージ（15,000人以上）／ヘッドライナー（60,000人以上）。
- ファンの増加 = (ファン数 × 0.05 ＋ 800) × (0.5 ＋ ライブ力/100) × 話題性補正
- 初めてその枠に出演したときは年表に記録する。

### 4.8 チャート・ダウンロード数・ランキング（決定：D08・D17・D26・D34）

#### ライバル

- 最初は架空のアーティスト10組。それぞれ実力（30〜58）を持つ。
- 毎年春：既存のライバルの実力が−0.5〜+3.5変化（上限95）。新人が1〜2組登場（実力 = 35〜62 ＋ min(年数, 15)）。14組を超えたら、実力の最も低い組が消える。
- 独立した元所属アーティスト（4.10）はライバルに加わる。実力は独立時の総合値で固定。チャートに「元所属」と表示する。
- ライバルの曲の出来 = 実力 × 乱数(0.8〜1.1)。10%の確率で+12（ヒット曲）。毎季5曲。
- ライバル事務所の経営シミュレーションは行わない（業界シミュレーションはF01）。

#### 季節チャート

- 対象：発表から3季以内（今季を含めて4季分）の楽曲。
- ポイント = 出来² / 100 × 経過による減衰 × ファン補正 × 乱数(0.95〜1.05)
  - 経過による減衰：発表した季1.0 → 0.8 → 0.55 → 0.3
  - ファン補正（所属曲のみ）：1 + log10(1 + ファン数/1000) × 0.25
- 内部ではこのポイントで順位を決め、画面には **ダウンロード数（ポイント × 1,000）** で表示する（D34）。換算値は `data.js` の `DL_PER_PT`。
- 上位10曲を表示し、前回順位と比べた上昇・下降・NEWを付ける。
- ファンの増加：所属曲の順位が10位以内ならポイント × (11−順位) × 40、圏外ならポイント × 8。話題性の補正あり。

- 所属アーティスト一覧（ファン数順。累計ダウンロード数・曲数・最大会場も表示。活動を終えた組も含む）

### 4.14 セーブ（決定：D17）

- ブラウザの localStorage に、操作のたびに自動保存する（キー `musicAgencyMock_v4`）。

### 4.16 自動管理・自動送り（決定：D47）

**D66で変更**：細かい設定はなくし、「自動モード」のオン・オフだけにした（ヘッダーの「自動」ボタン、またはメニューの「設定」タブのスイッチ）。オンにすると季節が自動で進み、下の表の運営もすべて初期値の基準で行う。オフ（手で進める）ときは、休養・発掘・迎え入れも含めて何もしない。基準は `AUTO_DEFAULT` に固定し、以前のセーブに入っていた設定は使わない。説明はヘルプの「自動モード」にまとめる。以下の表は基準の記録。

（D47時点の仕様）設定（ヘッダーの歯車のメニュー）で、それぞれオン・オフと基準を変えられる。設定はセーブ（`S.auto`）に入る。

| 機能 | 内容 | 初期値 |
|---|---|---|
| 休養へ移す | 調子がしきい値未満になった人を休養へ。元のトレーニングを覚えておく | オン・35未満 |
| 休養から戻す | 休養中の人の調子がしきい値以上になったら、覚えておいたトレーニング（なければバランス）へ戻す | オン・85以上 |
| 発掘 | 毎季、指定した場所でスカウトする（しない／4か所を順番に／場所を固定）。所属が上限のときはしない | 4か所を順番に |
| 迎え入れ | 見込みが指定の星以上の候補者を、見込みの高い順に空きがある分だけ迎え入れる | オン・★4以上 |
| 自動送り | ヘッダーの「⏩ 自動」で開始、「■ 止める」で停止。季節の結果を指定の秒数だけ見せてから次へ進む。結果を閉じると待たずに次へ | 4秒 |
| 止める場面 | 選択肢つきイベントと初の年間大賞では必ず止まる。ほかに、ライブ本番（D49）・受賞・誰かが辞めた・ランク／実績／殿堂の動き（それぞれ設定で選ぶ）。見せ場スキルを覚えただけでは止めない | すべてオン |

- 自動管理は、手で「次の季節へ」を押したときも、季節が進む直前に行う。行ったことは季節の結果の「自動で行ったこと」に載せる。

#### 自動送り中だけ行うこと（D55）

手で進めるときは行わない。設定でそれぞれオフにできる（初期値はすべてオン、`S.auto.train / form / release`）。どれも最適解は狙わず、見立てにブレをのせ、ときどき様子見で何もしない（手動の7割くらいの精度が目安）。

| 機能 | 内容 |
|---|---|
| 見立て | 将来性＝総合＋伸びしろ（素質−能力の平均）×若さ（21歳以下1、26歳以下0.7、30歳以下0.4、それ以上0.15）×0.8−（年齢−30）×3。所属している人は±8、候補者は±12のブレをのせる |
| 入れ替え | 所属が19人以上のとき、7割の季節で行う。今季の候補者のうち見立てが一番良い人が、所属で一番見立ての低い人より8以上良ければ、その人と契約を終えて迎え入れる（1季に1人まで）。推し・殿堂入りの組の人・入って1年未満の人は外さない。曲を出している組の人は+10して外しにくくする。所属が満員でも発掘する |
| 編成 | 組のない人（入って1季以上）がいれば、7.5割の季節で1組だけ組む。形態は各人の向いている形態の多数決（3割は2番目を選ぶ）。2人以上いるときは8割でグループの形態から選ぶ。人数は形態の範囲でランダム、メンバーは向き不向きにブレをのせて選ぶ。ひとりで1年待った人は、向いているソロ形態でデビューする。名前は自動 |
| トレーニングの見直し | 毎季、休養中でない人の3割を見直す。組にいれば、形態で大事な能力の上位2つのうち低いほうを伸ばす。組がなければ得意な能力（ブレあり）。2割はバランスにする |

- 自動シミュレーション（自動送りだけで20年）：入れ替えは年に0.6〜1人、所属の年齢は10代〜30代後半に散らばる。入れ替えなしだと、最後は30代後半〜50歳ばかりになり、組のない人が10人以上残っていた。
- 自動送りで止まったときは、理由を画面下のお知らせで出す。

### 4.17 ライブ本番（決定：D48）

ねらい：育てた人が「ここぞ」の場面で真価を発揮する瞬間を見せる。指示は自分、実行は育てた本人、にして「よく指示した」と「よく育てた」の両方が報われるようにする。

#### いつ起きるか（D49で拡張）
- 季節が進んだ直後に、次の優先順で1つ選ぶ（1季に1回まで）。本番になるのは持ち曲のある組だけ。
  1. 初公演：その季節に初めてホール・アリーナ・ドームで公演した組（大きい会場を優先）。
  2. 夏フェス：夏に、出演した組のうち一番大きい枠の組。隣のステージのライバルと対決する。
  3. 年末の大一番：冬に、いちばんファンの多い組。**毎年必ず1回**。最初から盛り上がり+6、成功率は−7%。
  4. 対バン：春と秋に45%で、ファンの多い組ほど呼ばれやすい。ライバルと対決する。相手は実力の近いライバルで、独立した元所属がいれば半々で元所属になる。
- 普段のライブは今までどおり自動。
- 自動シミュレーションでは年に約3回。
- 自動送り中は、設定「ライブ本番で止める」（初期値オン）なら止まって本番を見せる。オフなら「任せる」で結果だけ。
- 季節が進んだ直後、季節の結果より先に本番シーンになる。シーンの途中で閉じても、次に開いたときに最初からやり直せる（`S.liveScene` を保存）。

#### 流れ
1. 開演前：持ち曲の上位6曲から「1曲目（つかみ）」と「ここぞの1曲」（最後の曲）を選ぶ。2曲目は残りの持ち曲の最上位。足りなければカバー曲（出来45）。
2. 3曲を順に演奏する。各曲で盛り上がりが上がる（曲の出来・ライブ力。最後の曲は1.3倍）。
3. 見せ場が計4回（1曲目1回、2曲目1回、最後の曲2回）。主役は、形態で大事な能力のうち本人が得意なもの（スキルを持つ能力を優先し、同じ人・同じ能力は続きにくい）。
4. 見せ場ごとに指示を出す。成否は能力・調子・個性と運で決まる。大きな舞台ほど成功しにくい（会場・枠ごとに −7%）。

| 指示 | 成功率の目安 | 成功 | 失敗 |
|---|---|---|---|
| 攻める | 低め | +17 | −9 |
| 魅せる | 高い | +9 | +1 |
| 任せる | 個性次第（本番に強い・目立ちたがりは高め、天才肌・天然・自由人は振れ幅が大きい） | +12〜21 | −3〜−5 |

- 見せ場スキルを持つ能力なら、成功時に+4。ムードメーカーがいると毎回+2。「本番に強い」は成功率+8%、「繊細」は表現の見せ場で+8%。
- **覚醒**：盛り上がり80以上のとき、スキルを持つ能力の見せ場で「攻める」か「任せる」が成功すると覚醒する（+22）。画面では選ぶ前に「★ 覚醒チャンス」と出す。
  - 演出：客席がスローになって暗転する → 斜めの帯で顔が大きく切り込み、技の名前がドンと出る → 白く光り、客席が爆発する（紙吹雪）。
- 盛り上がりは0〜150。

- **合体スキル**（D49）：相性◎と判明している2人が、どちらも見せ場スキルを持っていると、1回のライブで1度だけ、ふたりの見せ場が来ることがある（最後の曲で60%、ほかで30%）。2人の能力・調子の平均で判定し、成功率+5%、成功時+6。覚醒すると「合体」として2人の顔が切り込み、+30。技の名前は2人の得意な能力の組み合わせで決まる（例：歌唱×演奏「魂の掛け合い」、ダンス×ダンス「シンクロダンス」。全21種、`data.js` の `COMBOS`）。
- **ハプニング**（D49）：2曲目のあとに45%で1つ起きる。

| ハプニング | 条件 | 選択肢と結果 |
|---|---|---|
| 機材トラブル | — | アカペラで乗り切る（カリスマ・表現で判定。+18／−10）／いったん立て直す（−2） |
| 雨 | 夏フェスのみ | ずぶ濡れで続ける（タフ・本番に強い人がいると有利。+16／−6）／屋根の下へ促す（+3） |
| 大合唱 | 盛り上がり50以上 | 選択なし。+12 |
| 目立たない人にスポット | 2人以上の組 | いちばん総合の低い人が対象。信じて任せる（若い・本番に強いと有利。成功で「殻を破る」の覚醒、+20／−6）／無難にこなさせる（+5） |

- **アンコール**（D49）：3曲を終えて盛り上がり100以上なら、手拍子のあとにもう1曲（使っていない持ち曲の最上位、なければここぞの1曲）。見せ場1回。
- **対決**（D49）：ライバルは実力に応じて、曲ごと（(2＋実力×0.11)、最後の曲は1.3倍）と見せ場ごと（実力÷100×4〜18）に盛り上がりを積む。画面にはライバルのゲージも出し、こちらの曲のあとに「ライバルのステージ」をはさむ。最後に上回れば勝ちで、ファンがさらに基準の5割増え、そのライバルの実力が1.5下がる。負けるとファンの増え方が半分になる。

#### 評価

| 評価 | 盛り上がり | ライブで増えるファン |
|---|---|---|
| 伝説 | 135以上（覚醒が1回以上必要） | ×2.2 |
| 大成功 | 100以上 | ×1.6 |
| 成功 | 75以上 | ×1.25 |
| まずまず | 45以上 | ×1 |
| 不発 | それ未満 | ×0.7 |

- 増えるファンは、基準×（倍率−1）。基準は、初公演なら収容人数の3割、夏フェスなら通常のフェスの増え方の6割、年末の大一番なら最大会場の収容人数の3割＋1000、対バンならファン数の4%（最低800）。
- 自動シミュレーションでの評価の散らばり（素直な育成）：全部「魅せる」だと成功が中心で覚醒は起きない。全部「攻める」だと不発も伝説も出る。全部「任せる」だとその中間で、伝説は1〜2割。
- 大成功以上と、元所属に勝ったときは年表に残る。
- ライブ本番の実績：覚醒、伝説のステージ、覚醒の常連（10回）、息の合うふたり（合体）、アンコール、殻を破る、対バン初勝利、巣立った者との再会（元所属に勝つ）、年の瀬の奇跡（年末の大一番で大成功以上）。

#### 見せ場スキル（D52で拡張）
- **能力スキル**：能力が70で覚え、85で上位版、95で最上位版になる。段階は強弱記号で **mf**（メゾフォルテ）→ **f**（フォルテ）→ **ff**（フォルティッシモ）と表す（D57。それまでは「初段・磨き・極み」）。同じ能力でも、人ごとに決まった**型**（主な能力以外の5つのどれか。人物のIDから毎回同じ結果になる）で名前が変わる。能力6つ×型5つ×3段階＝90種（`data.js` の `SKILL_TREE`）。
  - 例：歌唱・表現型「魂のハイトーン → 天を衝くハイトーン → 神域のハイトーン」、演奏・作曲型「即興セッション → 炎の速弾き → 伝説の速弾き」、カリスマ・歌唱型「コール＆レスポンス → 会場をひとつに → 五万人の心をひとつに」。
  - 段階が高いほど強い：成功したときの伸びは+4／+6／+8、覚醒の伸びは+22／+26／+30。
- **固有スキル**：能力のどれかが80に届くと、個性に応じた固有スキル（20種。例：本番に強い「土壇場の一撃」、天然「天然の奇跡」）に目覚める。その人の見せ場なら、能力スキルがない能力でも覚醒できる（能力スキルがあればそちらが優先）。
- **合体スキル**（21種）は、決めたときに図鑑に入る。
- 覚えたときは季節の結果の「事務所の歩み」に「習得」と出し、初めてのスキルなら「図鑑に登録」と添える（自動送りはこれでは止めない）。所属カードと名鑑には段階ごとに色を変えて表示する。
- **見せ場スキル図鑑**（歴史タブ、D57で作り直し）：
  - 表紙：題字、収録数と収録率のバー。
  - 見出しの帯：歌唱・演奏・作曲・ダンス・表現・カリスマ・固有・合体。それぞれ「覚えた数／全数」、全部そろうと★。
  - 能力の帯では、型ごとに1行で mf ▶ f ▶ ff の3枚を並べる。固有と合体はカードを並べるだけ。
  - カード：番号（No.001〜131）、段階のバッジ、紋章（能力・個性のアイコン）、名前、能力と型、説明（覚える条件と効果）、最初に覚えた人と時期。まだのものは「？？？」で、能力と型・個性・組み合わせだけ見せる（目標にできるように）。
  - 記録は `{t, by}`（通算季数、最初に覚えた人。合体は「A×B」）。古いセーブの記録は通算季数だけなので「登録済み」と出す。

#### 画面と音
- 全画面。上に組名と公演名（対決なら VS マークと相手）、「おまかせで最後まで」。中央にステージ、下に盛り上がりゲージ（80以上は覚醒圏として色を変える）と、語りと指示のボタン。
- 絵（D54、`images/live/`）：会場ごとの背景（160×72）、メンバーの全身の立ち姿（32×64を2倍。体の素材に、顔パーツから服を除いた頭を載せる）、客席の人影（3コマ×6種類）と最前列、ペンライト、照明（4色）、主役の足元の光、覚醒の衝撃、キラッと光る星、紙吹雪。
- 立ち姿のポーズ：ふだんは役割（歌・演奏・作曲が得意なら、マイク・ギター・キーボード）、見せ場ではその能力のポーズ（歌唱・演奏・作曲・ダンス・表現・カリスマ）。2コマを盛り上がりに合わせた速さで切り替える。
- 覚醒カットイン：帯の模様は `cutin_band.png` を流し、顔は64ピクセル版（`images/faces64/`）の覚醒の目と叫ぶ口。
- 盛り上がりに応じて5段階で変わる：照明の数と速さ、客席（h0 立つ、h1〜2 跳ねる、h3以上 両手を上げる）、ペンライトの数、立ち姿の動きの速さ、背景の明るさ。見せ場では主役にスポットが当たり、ほかは暗くなる。
- 音：喫茶店のBGMを止め、テンポ128のバンド演奏（盛り上がりで音が開き、手拍子が入り、高いとリードが歌う）と客席の歓声が流れる。覚醒の前にせり上がる音、決まった瞬間に衝撃音と大歓声。終わるとBGMに戻る。演奏はBGMの設定、歓声は効果音の設定に従う。

### 4.18 発表のショー（決定：D49）

季節が進んだあと、ライブ本番 → チャート発表 → 音楽賞の授賞式 → 季節の結果、の順に見せる（`ceremony.js`）。どれも「飛ばす」で残りをすぐに出せる。自動送り中は、チャート発表と授賞式は出さない。

- チャート発表：所属曲が3位以内に入った季節だけ。10位から順にめくり、3位からは間をあけ、1位は太鼓のあとで出す。所属曲は色を変えて判の音、所属曲の1位は紙吹雪。
- 授賞式：毎年冬。封筒を開けてから受賞者を出し、受賞者にはトロフィーを付ける。ライバル事務所の候補には印を付ける。賞ごとに候補を3つ並べ（年間大賞は年間チャート上位3曲、アーティスト賞は上位のアーティスト、作曲賞は出来の高い曲、新人賞はライバルの名前2つ＋受賞者）、太鼓に合わせて候補を順に照らしてから受賞者を出す。所属が取ったら金色に光り、紙吹雪。

### 4.19 ライバル事務所（決定：D53）

ねらい：自分と同じくらいの勢いで育つ相手と、毎年競い合う（`rival.js`）。

- 名前は候補から1つ選ぶ（`data.js` の `AGENCY_NAMES`）。新しいゲームでも古いセーブでも、最初に作る。
- **所属アーティスト**：2〜3組（D67。以前は2〜4組）。`S.rivals` に `agency:true` で入るので、エンジンのチャート・音楽賞にそのまま参加する。毎年春に、空きがあれば半々で新人がデビューし、4組を超えたら一番弱い組が活動を終えて新人と入れ替わる。数合わせのライバル削除（エンジンの `updateRivals`）では消さない。
- **勢い（factor）**：0.72〜1.15。毎季少しずつ上下し、0.85〜1.05 の範囲に戻ろうとする。
- **実力**：毎季、自分の最近（2年以内）の一番良い曲の出来×勢いに、半分ずつ近づく（看板の組が一番強く、2組目以降は6%ずつ下がる）。
- **ファン数**：自分の一番人気の組のファン数×勢い×0.7。ライバル事務所の曲にも、自分の曲と同じファン数の補正がかかる（エンジンの `songPts`）。
- **曲**：エンジンのライバル曲に加えて、毎季2曲（看板の組と、ほかのどれか）を出す。
- **事務所ランク**：自分の実績ポイント×勢いで決まり、一度上がったら下がらない。
- **事務所対決**：毎年、年間チャートのトップ10に入った曲のうち、それぞれ上位3曲のダウンロード数の合計で比べる（同じなら受賞数）。冬の結果に出し、年表に残す。通算成績と連勝を記録する。
- **ほかとの関わり**：対バンと夏フェスの対決相手は、半々でライバル事務所の組になる。ライバル事務所が受賞したら季節の結果に載せる。チャートとチャート発表・授賞式で印を付ける。
- **ホーム**：ライバル事務所のカード（名前、ランク、こちらとの上下、事務所対決の通算成績と連勝、今年のチャートのダウンロード数の比べ、所属アーティスト）。
- 実績：宿敵に勝つ（事務所対決に勝つ）、三年連続の凱歌、追い越した日（事務所ランクで上回る）。
- 自動シミュレーション（素直な育成）では、事務所対決の勝率は4〜7割。音楽賞はライバル事務所もかなり取るので、年間大賞は毎年取れるとは限らない。

### 4.20 シナリオモードとニューゲーム＋（決定：D64）

**シナリオモード**
- 条件つきの短い挑戦（1本20〜30分）。メニューの「モード」とタイトル画面の「シナリオに挑戦」から選ぶ。
- 本編とは別のセーブ枠（`musicAgencyMock_v4_scenario`）に保存する。本編の進み具合は消えない。最後に遊んでいた枠（`onbanbiyori_slot`）を覚えておき、次に開いたときはその枠から始める。挑戦中のシナリオは1つだけ。
- 中断して本編に戻れ、あとで「続きから」遊べる。メニューの「このシナリオをやめる」でシナリオのセーブを消して本編に戻る。
- ヘッダーの下に、シナリオ名・目標・残りの季節数の帯を出す。
- 毎季の終わりに達成を判定する。達成した年が早いほど★が多い（★3・★2になる年はシナリオごと。それより後は★1）。期限の年の冬が終わっても未達成なら「期限切れ」。結果の画面から、もう一度挑戦・ほかのシナリオ・本編に戻る・このまま遊び続ける を選べる。自動送りは結果が出たら止まる。
- シナリオごとのいちばん良い記録（★の数、早さ）を端末に残す（`onbanbiyori_scenario_rec`）。
- シナリオでは初めての年間大賞のエンドロールは出さない。

| つぶれかけの事務所 | 年間大賞 | 5年 | 3年目／4年目 | 25〜29歳の3人が組んだ組（素質−12、能力×0.75、ファン1,200）で始まる。オーディションは2人。ライバルの実力+12 | やさしめ（約80%） |

### 5.5 音（決定：D43）

- 音源ファイルは使わず、Web Audio でその場で合成する（`sound.js`）。ダブルクリックで開いても鳴る。
- BGM：テンポ72のゆったりしたジャズ。エレピの和音、ウッドベース、ブラシのドラム、ときどきヴィブラフォンの短いフレーズ。全体をこもらせ、回転むら・盤面のノイズ・針のプチプチを足して、喫茶店のレコードの雰囲気にする。32小節（A A B A）をくり返し、毎回少しずつ違う弾き方になる。
- 効果音（控えめ）：ボタン（小さなコツ）、タブ（紙の音）、次の季節へ（針を落とす音）、季節の変わり目（チャイム3音）、イベント（2音）、迎え入れ（やわらかい和音）、実績（判を押す音）、ランク昇格（判＋チャイム）、受賞（ベルの分散和音）。
- 設定（ヘッダーの歯車のメニュー）：BGMと効果音のオン・オフと音量。端末ごとの好みなので、ゲームのセーブとは別に保存する。
- ブラウザの決まりで、最初に画面を操作したときから鳴る。別のタブに移ると止まり、戻ると続きから流れる。
- BGMが流れている間、ヘッダーのレコードがゆっくり回る。

ドット絵の動き（D46、どれもゆっくり・コマ送り風）：
- 顔はときどきまばたきする（人ごとに間合いをずらす。疲れた顔はしない）。
- トレーニング部屋の人は小さく揺れる。ダンスは速め、ボイス・楽器・ステージは中くらい、休養はゆっくり呼吸して「z」が浮かぶ。
- 能力バーは、所属カードを開いたときに伸びる。
- BGM中はヘッダーのレコード、エンドロールでは金のレコードが回る。

ドット絵の動き（D69。今の素材だけで作る）：
- ホームの一番上に「事務所の前の通り」：今のランクの事務所の建物の前を、所属の人（全身の立ち姿）が4人まで歩く。右へ・左へ通り過ぎる、事務所に入っていく、出てくる。顔ぶれは季節ごとに入れ替わる。空の色と天気が季節で変わる（春は花びら、夏は光の粒、秋は落ち葉、冬は雪）。ホームの見出しの小さな建物の絵は外した。
- トレーニング部屋：顔の絵の代わりに全身の立ち姿で、その部屋の練習のポーズを2コマで動かす（ボイストレーニングは歌う、楽器練習は弾く、作曲合宿は書く、ダンスは跳ねる、ステージ経験は決める、バランスは人ごとにいろいろ、休養はゆっくり）。
- 新曲のジャケット：曲名とアーティストから決まる12×12のドット絵（モザイク・レコード盤・太陽と地平線・斜めの帯・図形の5種、配色8種）を、素材なしで描く。チャート・年間チャート・歴代ベスト・ライブ本番のセットリスト・チャート発表に出す。
- 動きを減らす設定（prefers-reduced-motion）のときは止める。

見せ場の1枚絵（D71。素材は images/illust/、依頼書は art_request_illust.md 版2.0）：
- 覚醒のカットイン：帯の背景を能力ごとの絵（cutin_能力.jpg。固有スキルは cutin_trait、合体は cutin_combo、「殻を破る」は表現の絵）にする。帯のふちは能力の色（合体は2人の色を上下に）、右上に能力の印をスタンプのように押す。顔は左、技の名前は右。
- 能力の色（ABIL_COLOR）：歌唱 朱 #d9573b、演奏 山吹 #e9a23b、作曲 藍 #3c6e91、ダンス 若竹 #5f9e6e、表現 藤 #8a74b0、カリスマ 紅梅 #cf4f7d、合体・固有 金 #e2b84a。見せ場スキル図鑑の印の丸の縁にも使う。
- 能力の印：画像（emblem_能力.png）を使うのは EMBLEM_PNG に入れた能力（D72で8つすべて）。入れていないものは、クリーム色の丸を能力の色で縁取り、ドット絵のアイコンを置く。印の中は透明なので、ゲームが輪の内側にクリーム色を敷く。見せ場スキル図鑑の能力スキルの印にも使い、まだ覚えていないものは灰色にする。
- 初めての大舞台（ホール・アリーナ・ドーム・夏フェスのヘッドライナー）：ライブ本番の始まりに1枚絵を画面いっぱいに出す（3.2秒か、押すと閉じる）。評価の画面の上にも同じ絵を帯で出す。
- 授賞式：幕の背景を授賞式の会場の絵に。年間大賞を取ったら、発表の瞬間の絵に替える。
- 殿堂入り：殿堂入りがあった季節の結果の「事務所の歩み」と、歴史タブの殿堂のページの上に絵を出す。
- エンドロール：一番上に夜の事務所の絵。届いた絵は縦長の枠の中に横長の絵が入っていたので、画面では横長の絵の部分だけを切り出して出す。
- オフライン用の最初の保存には入れず、見たときに保存する。

### 5.7 メニューとタイトル画面（決定：D65・D66）

**メニュー**（ヘッダーの歯車）：上部に「タイトル画面へ」と「閉じる」を常に置き、その下を4つのタブに分ける。開いたタブは覚えておく（同じ起動の間）。

| タブ | 中身 |
|---|---|
| 設定 | ステレオの操作盤ふうの枠。SOUND：BGM・効果音のスイッチ（ランプつき ON／OFF）と音量（レコードのつまみ）。AUTO：自動モードのスイッチ |
| ヘルプ | 遊び方と仕様（見出しを押すと開く。5.2）。「自動モード」の項目で、おまかせでやること・精度・止まるときを説明する |
| モード | シナリオ（挑戦・一覧・本編に戻る）、ニューゲーム＋ |
| セーブ | 「進み具合は、操作するたびに自動でセーブされます」。別の端末へ持っていくための セーブ（ファイルにセーブ・文字でコピー）と ロード（ファイルから・コピーした文字から）。やり直しのボタンは置かない（タイトル画面の「はじめから」で始め直す） |

**タイトル画面**：最初に事務所を始める画面を発展させたもの。起動するといつもここから始まる。
- **つづきから**：本編のセーブの事務所名・時期・周。セーブがなければ押せない表示。絵は事務所の今のランクの建物。
- **シナリオのつづき**：途中のシナリオがあるときだけ。
- **はじめから**：押すと事務所の名前の欄と「事務所を設立する」が開く。本編のセーブがあるときは、消えることを書き、設立のときにも確認する。セーブがなければ最初から開いておく。
- **シナリオ**・**ロード**：下に小さく並べる。
- 遊んでいる途中は、メニューの「タイトル画面へ」か、画面いちばん上の題字「音盤日和」を押すと戻れる。戻るときは自動モードを止めてセーブする。ライブ本番の途中のセーブは、つづきから入ったときに本番を最初からやり直す。

## 6. データ構造

ゲームの状態は1つのオブジェクト `S` にまとめ、そのままJSONにして保存する。

| フィールド | 内容 |
|---|---|
| ver, agency, year, season, nextId | 形式の版、事務所名、年、季節（0〜3）、連番 |
| people / alumni | 所属している人物 / 事務所を離れた人物（記録用） |
| units | 活動単位（活動を終えたものも含む） |
| songs | 楽曲（所属曲はすべて保持。ライバル曲はチャートの対象期間が過ぎたら削除） |
| candidates, scouted | 今季の候補者、スカウト済みかどうか |
| chart, yearPts, annual | 今季のチャート、その年の楽曲ごとのポイント、年間チャートの履歴 |
| awards | 音楽賞の履歴 `{year, name, winner, ours}` |
| rivals | ライバル `{name, power, ex}`（ex＝独立した元所属） |
| compat, known | 相性の値と、判明済みかどうか（キーは「小さいID-大きいID」） |
| pending, popup, report | 未解決の選択肢イベント、ポップアップ表示中か、直前の季節の結果 |
| dl | 事務所の累計ダウンロード数 |
| scoutSeenTurn | 発掘タブを最後に開いた通算季数（発掘タブの「!」用。D37で `app.js` が追加。古いセーブに無くても動く） |
| trainSeenTurn | トレーニングタブを最後に開いた通算季数（トレーニングタブの「!」用。D39。古いセーブに無くても動く） |
| history | 年表 `{t: 通算季数, text}` |
| achv, hall, rank | 実績の達成時期 `{実績ID: 通算季数}`、殿堂 `[{kind:'unit'|'person', id, name, type, year, members}]`、事務所ランク（D42） |
| auto | 自動管理・自動送りの設定（D47。初期値は `data.js` の `AUTO_DEFAULT`） |
| creditsPending | 初の年間大賞のエンドロールを次に見せるか |
| skillDex, dexInit | 見せ場スキル図鑑 `{スキル名: 通算季数}`、古いセーブの初回登録を済ませたか（D52） |
| agencyRival | ライバル事務所 `{name, factor, fans, score, rank, units[], record:{win, lose}, streak, results[]}`（D53）。所属アーティストは `rivals` に `agency:true, type` で入る。ライバル事務所の曲は `agency:true` |
| liveScene, liveStats | これから見せるライブ本番 `{uid, kind:'venue'|'fest'|'yearend'|'battle', idx, rival:{name, power, ex}}`、ライブ本番の記録 `{shows, awaken, legend, combo, encore, breakout, battleWin, exWin, yearendGreat}`（D48・D49） |

**人物**：id, name, age, abil{6種}, pot{6種}, train{6種}, traits[], policy, cond, unitId, joined, left, leftReason, fav, src（出身）, stars, hint, review, writer, prevOv, awards[], autoPrev（自動で休養へ移す前のトレーニング）  
**活動単位**：id, name, type, members[], formed, lastRelease, debut, fans, songs, dl, lives, attend, bestVenue, bestFest, awards[], active, ended, lastMembers[]  
**楽曲**：id, title, unitId, artist, type, members[]（発表時点の名前）, composer, q（出来）, t（発表時点）, ours, ex, total（累計ポイント）, peak, dl  
**季節の結果**：from, to, before{人物ID: {ov, abil}}, grow[], event[], song[], live[], chart[], award[], leave[], goal[]（ランク・実績・殿堂）, auto[]（自動で行ったこと）

人物と活動単位を分けて持つことで、編成や転向をしても人物の育成履歴が消えないようにしている（引き継ぎ書8.1の方針）。
