# 音盤日和

街角の小さな音楽事務所を育てる、ドット絵の育成シミュレーションです。ブラウザで遊べます。

才能を発掘し、トレーニングで育て、ソロやバンドを組んでデビューさせます。季節ごとに曲がチャートを争い、ライブ本番では育てたアーティストが見せ場で「覚醒」します。年間大賞、殿堂入り、ライバル事務所との対決を目指してください。

## 遊び方

- 公開ページを開くと、そのまま遊べます。
- ダウンロードした場合は、`index.html` をブラウザで開きます。
- 進み具合は、遊んでいるブラウザに自動で保存されます（端末をまたいでは引き継がれません）。
- 遊び方と仕様は、ゲーム内の歯車のメニューにある「ヘルプ」にまとめています。

## ファイル

- `index.html`：入口
- `style.css`：見た目
- `data.js`：ゲームのデータ（能力、トレーニング、イベント、スキルなど）
- `engine.js`：ゲームの基本の仕組み
- `app.js` ほか：画面、音、演出、ライブ本番、ゴール、ライバル事務所、自動送り
- `images/`：ドット絵の素材
