# 音盤日和

街角の小さな音楽事務所を育てる、ドット絵の育成シミュレーションです。ブラウザで遊べます。

才能を発掘し、トレーニングで育て、ソロやバンドを組んでデビューさせます。季節ごとに曲がチャートを争い、ライブ本番では育てたアーティストが見せ場で「覚醒」します。年間大賞、殿堂入り、ライバル事務所との対決を目指してください。

本編のほかに、条件つきの短い挑戦「シナリオ」（5本）と、年間大賞のあとに引き継いで遊ぶ「ニューゲーム＋」があります。

## 遊び方

- 公開ページを開くと、そのまま遊べます。
- ダウンロードした場合は、`index.html` をブラウザで開きます。
- 進み具合は、遊んでいるブラウザに自動で保存されます。別の端末で続きを遊ぶときは、メニュー（歯車）の「セーブ」タブでセーブして、もう一方でロードします。
- スマートフォンでは、公開ページをホーム画面に追加するとアプリのように開け、電波がなくても遊べます。
- 遊び方と仕様は、ゲーム内の歯車のメニューにある「ヘルプ」タブにまとめています。
- 起動するとタイトル画面が開き、つづきから・はじめから・シナリオ・ロードを選べます。遊んでいる途中も、画面いちばん上の「音盤日和」を押すと戻れます。

## ファイル

- `index.html`：入口
- `style.css`：見た目
- `data.js`：ゲームのデータ（能力、トレーニング、イベント、スキルなど）
- `engine.js`：ゲームの基本の仕組み
- `scenario.js`：シナリオモードとニューゲーム＋
- `app.js` ほか：画面、音、演出、ライブ本番、ゴール、ライバル事務所、自動モード
- `manifest.webmanifest`・`sw.js`：ホーム画面に追加したとき・オフラインで遊ぶときのためのファイル
- `images/`：ドット絵の素材と、見せ場の1枚絵（`images/illust/`）
- `docs/`：設計書（`game_design.md`）、絵の依頼書、素材の見本、スクリーンショット
